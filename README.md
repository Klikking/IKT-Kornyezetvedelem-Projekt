1. A projekt rövid bemutatása
A ZöldLépés egy digitális ismeretterjesztő projekt, amelynek célja, hogy gyakorlatias, tudományosan megalapozott és a mindennapi életben azonnal alkalmazható tanácsokat nyújtson a fiataloknak a környezetvédelem, az energiatakarékosság és a hulladékcsökkentés területén. A projekt keretében készült egy 4 oldalas Bootstrap alapú weboldal, egy 10 diás, egyedi diamintára épülő prezentáció, valamint egy 6 oldalas PDF formátumú digitális kiadvány.

2. Csoportmunka és Munkamegosztás

A projektet 2 fős csapatban valósítottuk meg. A feladatokat a vizsgakövetelményeknek megfelelően, egymás között arányosan osztottuk meg:
Szlifka Szilveszter: Projekttervezés, 5 szakmai forrás kutatása, a 4 oldalas Bootstrap weboldal kódolása és a 6 oldalas HTML/CSS alapú PDF kiadvány elkészítése.

Nagy Dávid Viktor: A 10 diás, egyedi Diamintát használó prezentáció elkészítése, a 5–10 perces bemutató videó felvétele, valamint a prezentáció és videó anyagainak GitHub feltöltése.

3. Felhasznált digitális eszközök
* Fejlesztőkörnyezet: Visual Studio Code (HTML5, CSS3, Bootstrap 5)
* Verziókövetés: Git, GitHub
* Prezentáció és Kiadvány: Microsoft PowerPoint (Diaminta szerkesztő), Canva (PDF kiadvány dizájn)
* Információgyűjtés: NÉBIH, MOHU, MEKH, WWF, EEA hivatalos publikációi

4. Eredmények összefoglalása
* Responsive projektweboldal (4 önálló oldal, Bootstrap 5 keretrendszerrel, átlátható navigációval).
* 6 oldalas digitális kiadvány (PDF) illusztrációkkal, gyakorlati csekklistával.
* 10 diás bemutató prezentáció egyedi mesterdiával, animációkkal és áttűnésekkel.
* Strukturált GitHub adattár rendszeres commit-történettel és teljes dokumentációval.
